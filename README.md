# How to install this mod menu?

You must complete these steps:

1. Go [here](https://github.com/gtgamingcpu-arch/AGtagMenu/releases) and download **AGtagMenu.dll**.
2. Drop the menu into your plugins folder.
3. Restart or run your game and **ENJOY AGTAGMENU!**
